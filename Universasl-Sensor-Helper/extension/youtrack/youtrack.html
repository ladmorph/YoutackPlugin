Сводная таблица по командам

Кликните по строке команды, чтобы посмотреть детализацию по сотрудникам. Кликните по любому числу в колонках "Бизнес", "Техн-кие", "Баги" или "Встречи/Иное" (подчёркнуто), чтобы увидеть полный список записей списания времени, из которых сложилась эта сумма. Кликните по проценту в столбце "Утилизация", чтобы увидеть, как именно он рассчитан. "Кол-во выпол. БЗ" — задачи с Тип: Фича и статусом READY FOR RELEASE, CLOSED или DONE. "В оценке" считается по закрытым бизнес-задачам с заполненной оценкой — показывается средний % и сколько из них превысили оценку (>100%); если над задачей работали несколько человек, их часы суммируются, все они видны в детализации.

Утилизация бизнес-емкости по проектам

График показывает суммарную утилизацию бизнес-емкости по каждому проекту (сумма часов "Бизнес" всех команд проекта / сумма их бизнес-емкости) за выбранный период.
