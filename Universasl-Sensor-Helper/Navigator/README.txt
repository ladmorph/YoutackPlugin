Личный Навигатор работает без подключения к Graylog и YouTrack.

Начальный список: links.csv, кодировка UTF-8.
Три столбца: Название;Ссылка;Описание
Ссылка http/https. Для заметки можно оставить ссылку пустой.
Пример строки (не обязательный):
Моя заметка;;Что нужно помнить
Если описание содержит переносы строк или разделитель, заключите его в двойные кавычки.

После изменения links.csv нажмите «Обновить CSV» в Навигаторе или откройте расширение заново.
Изменения из интерфейса сохраняются в chrome.storage.local данного профиля браузера.
Редактирование и удаление карточек не перезаписывают этот файл.
«Скачать CSV» экспортирует текущий список; файл можно вручную положить вместо links.csv.
«Импорт CSV» добавляет записи; для одинакового названия и ссылки обновляет заметку.
Персональные заметки не отправляются на сервер. Удаление расширения может удалить локальные данные — используйте экспорт для резервной копии.
