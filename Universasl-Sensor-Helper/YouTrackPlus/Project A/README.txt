Project A — стартовая папка проекта отчёта.

Положите сюда teams.json с командами вашего проекта.
config.json необязателен: он задаёт собственные правила классификации.
work_items.json нужен только для локального отчёта из готовой выгрузки.

В + YouTrack нажмите «Подключить папку» и выберите YouTrackPlus рядом
с manifest.json. После этого Project A появится в списке проектов.
Папку можно переименовать; затем нажмите «Обновить список».

Настройки можно создать в конструкторе и сохранить кнопкой
«Сохранить команды и правила в проект».
Название папки не предоставляет прав доступа к проекту YouTrack.
