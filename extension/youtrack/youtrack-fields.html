Как собрать отчёт

Прежние проекты, teams.json, config.json, списания и Excel. Все настройки и расчёты сохранены.

Здесь только просмотр и выгрузки. Настройка и запуск обоих способов — во вкладке «Отчёт».

1

Подключение

Используйте уже открытую и авторизованную вкладку YouTrack.

Штатная сессия YouTrack

На странице YouTrack нажмите у помощника «Подключить», затем перейдите на главную. После получения токена откройте + YouTrack.

Подключение без открытой вкладки

Запасной вариант для автономного отчёта: OAuth PKCE или временный permanent token.

Администратор Hub создаёт публичный OAuth-клиент без client secret, включает Authorization Code + PKCE и регистрирует Redirect URI выше.

Временное подключение permanent token

Токен создаётся в профиле YouTrack. Он хранится только до перезапуска браузера и никогда не попадает в URL или отчёт.

2

Проекты и команды

Без файлов: каждый проект считается одной командой.

Автоматический

Проекты YouTrackPlus

Выберите папку YouTrackPlus — её подпапки станут проектами отчёта.

YouTrackPlus / Проект А / teams.json, config.json. work_items.json можно добавить для отчёта из выгрузки. При выборе папки-родителя внутри неё будет создана YouTrackPlus. Переключение не запускает сбор отчёта. Сохранение заменяет только teams.json и config.json выбранного проекта.

Что нужно для вашего отчёта

Проверяю файлы в папке расширения…

Команды и участники

Проверяю teams.json…

teams.json делит проекты на ваши команды, задаёт участников и ёмкость. Без него отчёт объединяет людей по проектам.

Стандартные правила

config.json нужен, если у вас свои названия полей оценки, статусов или типов задач. Правила также можно настроить ниже.

Отчёт из файлаДля готовой выгрузки · необязательно
Из YouTrack после подключения

Выберите готовую выгрузку work_items.json, чтобы построить отчёт локально, без запросов к YouTrack. При обычном подключении этот файл не нужен.

Положили файл в папку? Это должна быть папка, выбранная при «Загрузить распакованное», рядом с manifest.json (или её подпапка extension). Нажмите «Проверить папку ещё раз». Если файл не найден — выберите его кнопкой выше. Проверка файлов не обращается к YouTrack и не запускает отчёт.

Период и запуск

Запросы выполняются только после нажатия кнопки.

Готово к запуску
Повторный расчёт использует готовый результат до 2 минут. Обновление заново загрузит данные.

Сырые страницы обрабатываются по мере загрузки и не записываются на диск. Локально сохраняются только настройки профиля; токен живёт в памяти сессии браузера. Между порциями — 20 мс после ответа.

Проверки отчёта и списания участников

Выберите проект и период на вкладке «Отчёт», затем нажмите «Построить отчёт».

Графики

Списания участников, ёмкость и оценки по уже собранному отчёту. Новых запросов в YouTrack нет.

Network и запросы

Штатные вызовы YouTrack и запросы расширения: метод, безопасный путь, наличие Bearer, статус и время. Host, значение токена, query-параметры и тела сюда не попадают.

Конструктор JSON

Соберите или поправьте профиль команд и правила отчёта. work_items.json остаётся фактической выгрузкой и здесь не редактируется.

Что здесь хранитсяНазвания проектов, команд, логины, ёмкость и правила. Изменения применяются к отчёту только отдельной кнопкой.

teams.json

Проекты, команды, участники и условие закрытой задачи.

config.json

Какие списания и задачи попадают в колонки отчёта.

Проверка и выгрузка

Предпросмотр обновляется только после проверки, поэтому ошибки не попадут в файл.
