Как определяется одинаковая ошибка?

Сравниваются категория, сервис и признаки из таблицы ниже. Полный текст сообщения не сравнивается. В режиме релиза обе версии ищутся внутри выбранного периода. В режиме сравнения периодов история заканчивается в момент начала текущего периода; её длительность выбирается отдельно.

ПроверкаЧто должно совпасть

Например, разные SQL-ошибки одного сервиса объединяются в одну группу. Метка «новое» означает новую группу в доступной выборке, а не доказательство появления конкретного текста ошибки впервые. «Новое в релизе» также не доказывает, что причиной был релиз.

Проверки выполняются последовательно. Для релиза дополнительно запрашиваются только счётчики версий внутри выбранного периода. История нужна лишь для сравнения периодов.

Результаты поиска

Маршрут traceId

Узлы сгруппированы по service-name + spanId и расположены по времени REQUEST. Верхняя стрелка показывает предполагаемый путь запроса, нижняя — обратный путь RESPONSE. Для точной причинной связи между параллельными ветками нужен отдельный parentSpanId.

Вызовы Graylog

Штатный поиск traceId и явно запущенные вызовы расширения. Логин, cookie, host Graylog, идентификаторы запроса и сообщения сюда не попадают.
